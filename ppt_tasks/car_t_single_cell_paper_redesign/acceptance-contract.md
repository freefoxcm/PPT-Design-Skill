# Acceptance contract

## MUST

- 12-slide, 16:9 editable PPTX with a reproducible Build Mode source script.
- Narrative: clinical persistence → cohort/design → atlas → BCA axis → type 2 state → candidate mechanism → longitudinal serum → in-vivo test → IL-4 engineering → evidence ladder → conclusion.
- Every data page has one dominant evidence figure or editable diagram; selected panels remain readable at 1280×720.
- Quantities remain tied to the paper: 82 patients, 6 healthy donors, 695,819 cells, 17 cell states, five BCA strata, 8.4-year median BCA-L duration, 30 cytokines, 345 measurements, reported doses and mouse timing.
- Every paper-evidence page has a visible figure/source caption. Conceptual cover art is marked conceptual.
- Association, candidate mechanism, and preclinical evidence remain explicitly separated.
- No repeated four-card dashboard template across the majority of pages.
- Render PPTX → PDF → PNG and inspect every PNG before delivery.

## SHOULD

- Use 5–6 distinct page archetypes with shared typography, margins, and semantic color roles.
- Prefer one large source figure plus editable annotations over multiple tiny full-figure screenshots.
- Keep source notes readable without zooming into the slide.

## NICE TO HAVE

- Add a compact figure index or evidence legend that helps the audience navigate the paper.
