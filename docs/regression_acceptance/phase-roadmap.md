# 项目阶段路线图

## 阶段一：端到端流程验证（当前阶段）

目标不是把三个案例打磨到最终交付级，而是证明新 skill 系统的完整工作链路可运行，并且 upgraded 结果相较 baseline 有明确改善。

验收条件：

- 三个不同领域案例均可生成 editable PPTX；
- 三套 baseline / upgraded 文件对独立、页数一致、控制变量可追溯；
- 所有 upgraded PPTX 均完成 PDF / PNG 渲染；
- 每页都有 Acceptance Record 评分和证据；
- MUST 条件能够逐项检查；
- 第二 Reviewer 流程有明确输入、输出和签字位置；
- 对视觉改善的结论基于实际 PNG，而不是只基于代码运行成功；
- 尚未完成的案例精修被明确标记，不影响流程验证结论的边界。

## 阶段二：案例精修与新案例扩展

阶段一跑通后，再处理：

- AI Infrastructure 的视觉语言收敛；
- CAR-T 密集科研图版的演示可读性；
- Louvre 的品牌细节和建筑叙事精修；
- 新增不同领域案例；
- 统一素材来源、图表语言、版式系统和设计 tokens。

## 阶段三：效果稳定化

- 固化高质量参考集；
- 对相同 brief 做重复生成测试；
- 比较不同案例的视觉评分方差；
- 建立常见缺陷清单和自动化预检；
- 只有稳定达到门槛的案例，才进入正式参考集。

## 当前状态

阶段一已完成主要资产准备和部分验证：baseline、upgraded 输出、渲染产物、Acceptance Record、逐页评分和第二 Reviewer 清单均已建立。剩余工作是跑完统一流程并形成“新系统相对 baseline 的证据化改善报告”。
